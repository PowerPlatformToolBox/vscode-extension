# Marketplace Screenshot Guide

This folder tracks the screenshot set for Marketplace listing quality.

## Required Captures

- 01-connections-view.svg (replace with .png when real capture is available)
    - Show populated Connections view with active connection indicator.
- 02-marketplace-view.svg (replace with .png when real capture is available)
    - Show marketplace browsing with install action visible.
- 03-installed-tools-view.svg (replace with .png when real capture is available)
    - Show installed tools list and launch action.
- 04-feedback-commands.svg (replace with .png when real capture is available)
    - Show Command Palette with:
        - PPTB: Report a Bug
        - PPTB: Request a Feature
        - PPTB: Open Issue Tracker
        - PPTB: Join PPTB Discord

## Capture Rules

- Use a clean profile and realistic sample data.
- Avoid secrets, tenant IDs, and access tokens.
- Prefer 16:9 captures where possible.
- Keep UI text readable at Marketplace preview size.

## Update Process

1. Capture updated images when major UI or command names change.
2. Replace files in this folder using the same names.
3. Verify images render correctly in README before release.
